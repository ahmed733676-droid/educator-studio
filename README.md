# Educator

Teaching studio for dental demonstrators. Third tool in the family:

- **Risala** writes the thesis
- **Auctor** checks it
- **Educator** teaches the clinic

Static. No backend. No invented results.

## Open it

Open `index.html` in a browser. On iPhone: unzip, open Files, tap `index.html`.

Hash routes work from `file://`. Progress sits in `localStorage` under `educator.progress`.

## Courses that are live

1. **RPD Design Studio** — five-step map (survey → rests → connectors → retainers → finish), Kennedy I case, 30-minute demo with a clock, photographable board, prop list.
2. **Closed sinus lift, 4–5 mm band** — indication window, bounce, abort rules. Six-month outcomes are *not* in this product. They live in `Abdallah_Results_CRF.xlsx` and stay dashed until the 26 cases are entered.

OSCE: 10 stems, live mark, demonstrator-voice model answers. Paper mode or exam mode.

Locked stubs only: all-ceramics, immediate implant, PRF.

Mohamed Ayman Abdallah (Pharos M.Sc., closed sinus / 4–5 mm band, n = 26) stays a thesis. Educator is the teaching product next to it.

## Stack

HTML + CSS + vanilla JS. Fraunces + IBM Plex when the network is up; Palatino / system-ui when it is not. Dark academic plate (ink / paper / brass).
